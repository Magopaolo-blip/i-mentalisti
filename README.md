# I Mentalisti

Landing page in italiano e inglese di Paolo Musetti e Riccardo Bramati.

Pubblicazione GitHub Pages: branch main, cartella root.

Il modulo prepara una richiesta WhatsApp. Per attivare l'invio email, configurare un endpoint Formspree dedicato in assets/site.js e aggiornare l'informativa privacy e le etichette del modulo.
